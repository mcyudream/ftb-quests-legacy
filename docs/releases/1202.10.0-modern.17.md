# FTB Quests Legacy 1202.10.0-modern.17

Minecraft 1.12.2 / 正式 Cleanroom 0.4.0（无 alpha）/ Java 25。正式修复版。

## 修复 Windows 自动保存崩溃

- 修复将整个 `config/ftbquests/normal` 目录移入备份时触发 `AccessDeniedException`，导致世界自动保存崩溃的问题。
- 保留正在使用的任务目录及未改动文件；完整备份、预写事务记录后，逐个原子替换有变化的文件。失败时回滚，启动时恢复未完成的事务，并兼容 modern.16 及更旧版本的 UUID 事务记录。
- 自动保存发生 I/O 错误时保留内存编辑和待保存状态，间隔 5 秒重试。完全序列化后发生的提交失败会保留 `.normal.stage-UUID` 快照，日志给出位置。权限、磁盘空间或文件锁长期阻止写入时仍须解除对应限制；不要删除尚未恢复的事务记录或备份。
- 不改变 SNBT / NBT 任务布局、任务 ID、团队 UID、进度、领奖记录或未知扩展字段。

## 安装与验证

客户端与服务端替换 Quests 为 `FTBQuests-1202.10.0-modern.17.jar`，配套使用 `FTB-Library-NovaEng-5.5.4-modern.4.jar`；Utilities modern.2 不变。ItemFilters 1.0.4.2 独立安装。不要把源码包放进 mods。媒体继续使用原有可选 Media API。

正式 CR 0.4.0 专服未安装 Ponder 或同等 Kirino 客户端隔离修复时，额外安装本 Release 的 `Cleanroom-0.4.0-Server-Compatibility-1.0.0.jar`；客户端无需此补丁。

CI 包含 Quests 87 项、Library 10 项、专服补丁 2 项测试，以及 Windows 原生目录占用、文件共享锁、回滚与解锁重试测试。标签发布必须通过 Linux 构建和 Windows 存储检查。完整 Windows 整合包未实机验收；Windows 文件系统回归与 Linux 上正式 CR 0.4.0 的客户端、专服任务读写分开记录。
