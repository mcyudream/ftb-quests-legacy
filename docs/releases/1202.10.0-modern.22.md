# modern.22：隐藏思索按钮提示中的 ID

正文中的 `ponder` 组件不再向悬停提示自动追加原始目标 ID，例如 `ae2:spatial_storage_cell_128#ae2s_ponder:spatial_io`。

默认仍显示“查看思索演示”，显式配置的 `hover` 提示继续生效。按钮文字、物品图标、点击目标、任务存储和编辑器中的教程 ID 搜索沿用原行为。

从 modern.21 更新时替换 `FTBQuests-1202.10.0-modern.22.jar`。继续使用 Library `5.5.4-modern.8`、Utilities `5.5.1-modern.2` 和 ItemFilters `1.0.4.2`。

本地构建通过 89 项现有 Quests 单元测试，并在正式 Cleanroom `0.4.0`、Java 25 上通过有／无 Ponder 的客户端与专服回归。提示删除已检查源码和打包后的字节码；本次未采集游戏内悬停截图或复测场景播放。详见 [本版验收与发行记录](../../verification/modern22/README.md)。
