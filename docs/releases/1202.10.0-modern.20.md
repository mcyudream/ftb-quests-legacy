# FTB Quests 1202.10.0-modern.20

Minecraft 1.12.2 / 正式 Cleanroom 0.4.0（无 alpha）/ Java 25。

## 物品搜索延迟修复

- 修复每次查询都遍历全物品并重新查拼音 LRU 缓存的问题。中文名称超过 32768 个时会不断淘汰并重新转写，注册名搜索也被拖慢；现由物品索引持有检索键，后续查询不再做全量拼音转换。
- 拼音索引按新增条目增量准备，避免重复预热整个旧快照。中文名称和注册名搜索无需等待后台拼音准备完成；拼音索引的新增结果自动更新当前查询。
- 移除固定 200 毫秒等待与逐字清空列表。新查询立即取消旧查询，只有当前关键词／模式的结果可以更新界面，避免旧线程覆盖较新的搜索。
- 保留中文、拼音、首字母、注册名和 `@模组名` 搜索；背包模式仍使用原物品栈副本，保持 metadata／NBT。
- 保留 modern.19 的 Windows 原输入框输入法激活及章节右键编辑修复，不增加外部编辑窗口。

客户端与服务端一起替换 **Quests modern.20、Library modern.8**。使用 Utilities 时也替换本次重新编译的 modern.2；ItemFilters 1.0.4.2 仍独立安装，Media API／Ponder 保持可选。

任务格式、ID、未知字段、进度及领奖数据保持兼容。大量物品的对比数据与验收范围见 [验收记录](https://github.com/mcyudream/ftb-quests-legacy/blob/main/verification/modern20/README.md)。
