# FTB Quests Legacy 1202.10.0-modern.16

Minecraft 1.12.2 / 正式 Cleanroom 0.4.0（无 alpha）/ Java 25。**正式发行，非预览版。**

## 安装

客户端和服务端同时更新 Quests modern.16、Library modern.4；原整合包使用 Utilities 时采用 modern.2。安装普通 `.jar`，不要安装源码包或编译 SDK。ItemFilters 1.0.4.2 从原发布渠道独立安装。

## 更新

- 中文编辑：输入框“中”按钮或 F4 打开系统输入法窗口，确认回填、取消不改原文；正文保留多行、撤销与重做。
- 物品和思索按中文名称、全拼、拼音首字母搜索；保留英文、注册名、教程 ID 及物品 @模组过滤。思索选中后保留精确场景 ID。
- 更柔和的详情、章节、悬停、画布缩放和奖励开箱动画；编辑模式即时响应。
- 保留旧 Nova 任务格式、未知字段、整数 ID／团队 UID、进度和领奖数据；修复加载顺序环及大任务书新增节点处理开销。
- 新增可独立构建的多模块源码、哈希锁定依赖、GitHub Actions 构建／测试／标签发布与校验文件。

可选 Ponder、CraftTweaker／ZenScript、Media API、MCP 运行库独立安装。本 Release 发布三个 FTB 模组，未重新分发 Media API 内的第三方媒体后端。既有视频接入代码保留。

## 验证与边界

CI 执行 Quests 78 项 + Library 10 项测试。正式 CR 0.4.0 的实际客户端、专服及任务读写证据随源码提供；生产包检查排除验收类和编译 SDK。SHA256SUMS 校验发行文件，BUILD-INFO.json 记录源码提交与生产条目摘要。

Linux x86_64 已验证；Windows/macOS、完整整合包和系统输入法真实候选词按键流程未自动实测。中文窗口的原生控件、上下文、确认／取消及回填已检查；其不是对 GLFW 底层输入法实现的替换。
