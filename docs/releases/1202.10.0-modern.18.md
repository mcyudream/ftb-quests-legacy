# FTB Quests 1202.10.0-modern.18

输入修复测试构建；人工系统输入法测试正在进行。验收范围见 [输入回归记录](../../verification/modern18/README.md)。

## 输入焦点修复

- 鼠标点击先同步实际事件坐标，修复快速从标题移到正文时光标仍定位到上一行的问题。
- FTB Library 输入控件统一管理焦点，每个界面只允许一个文本输入框接收键盘输入。修复按钮或面板截断点击分发后，旧输入框仍保留焦点的问题。
- 正文、标题、副标题之间互斥；窗口缩放和编辑器重新布局保留当前输入目标；预览、工具栏、组件表单和选择器返回时更新焦点。
- 关闭子窗口后按当前界面恢复按键重复状态，避免长按退格等操作失效。
- 补充汉字的单行光标移动、多行换行、鼠标选择和替换以完整字符为单位，避免拆开 UTF-16 代理对。
- 配套 Library modern.6。客户端与服务端同时更新；使用 Utilities 的整合包也替换本次重新编译的 modern.2 JAR。

不改变原任务数据格式。
