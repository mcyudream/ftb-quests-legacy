# modern.21：章节名称悬停修复

修复 modern.20 中将鼠标移到任务书侧栏图标后不显示章节名称的问题。

FTB Library 的父面板只对启用的控件执行 tick。章节浮层先前在关闭时将自己标记为禁用，导致自身的悬停检测无法启动。现在浮层继续接收 tick，并单独判断是否允许鼠标交互；关闭、淡出和再次悬停均能正常执行。

覆盖普通浏览、编辑模式、关闭章节动画、侧栏滚动后的父子章节名称及点击选择。不改变章节标题的存储、翻译解析、任务 ID、任务进度或领奖记录。

从 modern.20 更新时替换 `FTBQuests-1202.10.0-modern.21.jar`。继续使用 Library `5.5.4-modern.8`、Utilities `5.5.1-modern.2` 和 ItemFilters `1.0.4.2`。Ponder 为可选依赖；同时修复其 `/pondergui` 命令时另更新 Ponder 到 `1.7.2`。

验证基线为正式 Cleanroom `0.4.0`（不带 `-alpha`）、Java 25。有／无 Ponder 的客户端与专服检查通过；Quests 89 项、Library 15 项、专服补丁 2 项单元测试通过。任务模型、网络和保存工具的 231 个 class 与 modern.20 逐字节一致。

测试使用实际安装 JAR 和独立验收模组；窗口未聚焦时，验收通过 GuiWrapper 注入鼠标坐标，保留实际父控件 tick、布局、渲染与点击处理。运行于 Linux x86_64 / llvmpipe；Windows/macOS 完整游戏、其他 GPU 和完整用户整合包未验证。报告与截图见 `verification/modern21/summary.json`。
