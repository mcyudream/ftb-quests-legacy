# FTB Quests 1202.10.0-modern.19

Minecraft 1.12.2 / 正式 Cleanroom 0.4.0（无 alpha）/ Java 25。

## Windows 输入法与章节右键修复

- 自绘输入框接入原版 `GuiTextField.setFocused()` 的平台焦点通知，让 Cleanroom 在选中标题、副标题、正文和搜索框时启用系统输入法。此前仅修正了 Java 内部焦点，Windows 的输入法上下文仍处于关闭状态。
- 使用原版焦点入口，兼容正式 CR 0.4.0 的 IMM 路径及较新版本的后端；不新增编辑窗口、不重新绑定 F 键。原输入框继续接收中文字符。
- 修复章节侧栏图标的空点击回调：直接左键切换，右键打开与展开章节相同的移动、编辑和删除菜单，无需等待悬停。保留原编辑权限检查。
- 修复画布在鼠标位于章节侧栏时仍消费右键并打开添加任务菜单的问题；画布操作限定在画布区域。
- CI 增加 Windows 原生 IME 上下文关联／解除／重新启用检查，使用正式 CR 0.4.0 的 Windows 处理器与实际 Win32 窗口。此检查未模拟微软拼音候选词按键，不能代表完整 Windows 游戏验收。

客户端和服务端一并替换 **Quests modern.19、Library modern.7**；使用 Utilities 时也替换本次重新编译的 modern.2。ItemFilters 1.0.4.2 仍独立安装。Media API 保持可选。

任务数据格式、ID、进度及领奖数据保持兼容。验证范围与参考实现见 [验收记录](https://github.com/mcyudream/ftb-quests-legacy/blob/main/verification/modern19/README.md)。
