# 功能对应与边界

本版继续使用 Nova 1.12 任务与团队模型。现代实现中的 API、文件布局和依赖按 1.12.2 可用接口重写，不宣称能够直接安装现代附属 JAR，或导入其 64 位任务文件。

## 中文输入与拼音搜索（modern.16）

输入框“中”按钮／F4 打开系统输入法编辑窗口，支持系统候选词、中文标点、标题和多行正文，确认回填，取消不改原文；游戏可直接收到的 Unicode 输入仍走原路径。物品与思索选择器支持全拼和拼音首字母，并保留中文／英文、注册名／教程 ID 搜索。使用 Cleanroom 的 ICU，后台生成缓存，无额外 Mod 前置；需配套 Library modern.4。参见 [中文输入与搜索](INPUT-AND-SEARCH.md)。

## 界面动画（modern.15）

详情窗口采用独立 320 ms 淡入／淡出及轻微缩放，遮罩独立渐变；章节浮层用 350 ms 淡入淡出与短距离位移。导航图标保留亚像素缩放，悬停／画布缩放保留反向时的速度。开箱开盖、转盘起止及结果展示也已调整。显示设置补齐通用、侧栏、详情三项时长；编辑模式仍即时响应。细节、低配回退及验收边界见 [动画配置与验收](ANIMATIONS.md)。

## 加载顺序、侧边栏与新增节点（modern.13）

去掉任务 Mod 对 Ponder 的启动排序约束，避免经过 ZenUtils / ModularMachinery 形成间接依赖环；可选 Ponder 类仍隔离到客户端桥接包，玩家点击或打开选择器时调用。使用实际 Forge 排序器复现旧规则的间接环，并检查新规则在 16 种输入顺序下、缺少 Ponder / Media API 时和后接教程附属时均可排序。

侧边导航图标、辉光与章节面板新增独立 **350 ms** 默认动画时长，可通过“显示设置”调整。新建节点、任务与奖励只登记新增 ID，更新所属任务的按钮，保留其他节点的显示缓存与 JEI 实例；保存沿用内存修改、自动保存和退出写盘。具体说明见 [加载顺序与编辑性能](LOADING-AND-EDITING.md)。

## 客户端视频与直连（modern.12 / Media API 1.0.4）

视频导入只复制到客户端 `config/ftbquests/media/`，原 `media:` 字段与哈希命名保留；`local:` 仍对应客户端 `config/ftbquests/videos/`。缺文件时失败，客户端不请求服务器，服务器也拒绝视频上传/下载包。旧缓存存在时只读复用；图片上传与下载协议继续使用。

视频元数据使用独立 TLS 上下文和显式 DIRECT 代理选择器；在线内容通过 Java 的直连 HTTP 读取回调传入 VLC，包含 Range / Referer / User-Agent，每次回调最多读取 64 KiB，无视频临时文件，不修改进程或系统代理。HTTP 不支持 Range 时不会启用可拖动进度。分离音轨暂转网页，避免原生从代理另取音轨。

抖音识别公开分享链接及分享文本，客户端取得平台匿名 `ttwid` 后读取分享页，只选取视频 ID 匹配且确实含视频数据的作品；路由层和统计层的相同 ID 不会导致提前失败。票据只存在内存中，30 分钟刷新，元数据失效时最多重新注册一次；不读取账号 Cookie，不发送给 CDN 或游戏服务器。兼容 `playApi`。用户短链 `IVOk7RWtfKU` 已在正式 Cleanroom 0.4.0 中通过实际视频帧、暂停、时间轴定位与重新解析播放；开启环境与 JVM 代理时视频请求 0 次进入代理，未写视频缓存。平台受限内容或接口策略变更仍可能失败，提供本地化错误、重试和网页图标。

## 单人存档加载热修复（Library modern.3）

旧校验把随机分配时保留的 UID 2 一并当作非法持久数据，导致正常单人团队在重进世界时被拒绝加载。加载现在允许已有 UID 2；新团队分配仍保留 0 / 1 / 2，UID 1 和真实重复 UID 的拒绝逻辑保留。任务书、团队 ID、进度与领奖记录的保存格式保持原样。已安装 modern.11 的实例只更新 Library 即可；实际验收见 [热修复报告](../../ftb-library/verification/REPORT.md)。

## 本地化修复（modern.11）

显示设置使用 FTB Library 归一化后的实际配置 ID 查找翻译，保留旧驼峰翻译键作为兼容项。补齐现有英文语言键的缺失中文，覆盖任务与奖励字段、右键菜单、画布和配套 Library / Utilities；批量编辑的属性标签复用任务字段翻译，快捷键及隐藏任务提示改用语言键。

Library modern.2 为布尔 GUI 值和通用配置提示提供本地化显示；`getString()`、NBT、网络布尔及命令字面值继续使用原语义。新版任务与 Utilities 通过 Library 的版本依赖要求匹配的运行库。更新需替换三份 JAR。

静态审计脚本 `tools/audit_localization.py` 检查重复键、英文键的中文覆盖、格式参数以及显示设置的实际小写 ID。运行验收另检查真实配置表单和右键菜单生成的标签，避免仅比较语言文件而遗漏动态键。

## Markdown 教程选择器（modern.10）

Markdown 模式的工具栏“思索演示”直接打开现有元数据搜索选择器，点击教程即在光标／选区位置插入原生 `ponder:` Markdown 链接。选中文字作为标题，否则使用列表中的教程名称。自动转义标题中的括号、反斜线及格式字符，避免标题被识别为其他链接或样式。搜索框自动聚焦；取消保留文本和选区，插入沿用本地撤销历史，一次 Ctrl+Z 即还原。

原版模式与组件菜单的 JSON 表单继续提供原搜索选择器；已有任务不自动切换正文模式，不新增数据字段。无 Ponder 时点击提示并保留草稿。

## 任务内 Ponder 链接（modern.9）

Ponder 为 `compileOnly` 可选兼容，独立安装；仅在检测到 `ponder-legacy` 后进入客户端适配包，专服不初始化动画／图文界面。SDK 与验收运行库的固定版本及 SHA256 记录在 `ponder-compat.lock.json`，构建核对 SDK；运行库不打入任务 JAR。

编辑器的“思索演示”按钮提供按物品名／物品 ID／教程标题／教程 ID 搜索的选择器。枚举注册元数据，不为搜索编译全部场景。目标格式为 `namespace:item` 或 `namespace:item#namespace:tutorial`，原物品目标继续使用。正文 JSON 按钮与 Markdown `ponder:` 链接共用跳转；预览不执行动作。组件编辑保留额外字段，跟随已有编辑保存协议，不增加任务存储格式。

Ponder Legacy 1.5.0 的动画、图文和仅图文教程分别适配；具体教程 ID 可映射到不同的动画 ID，显式仅动画目标不被图文偏好替换。1.4.1 使用动画接口回退。关闭或 Esc 返回任务书；缺少可选模组／教程／目标格式错误时显示中文或英文提示。链接只引用已有教程，不注册内容或下载资源。

## 奖励开箱（modern.8）

手动领取 `random` / `loot`（含重复随机奖励）以及右键使用战利品箱触发开箱动画。界面使用 `FTBQuestsTheme` 的背景、字体颜色、按钮与容器槽，宝箱为 Minecraft 原生 `ModelChest`，纹理使用资源包里的 `minecraft:textures/entity/chest/normal.png`。开盖后滚动减速，最终展示服务器已发放的结果。手动选择奖励与全表奖励维持其原有流程。

新结果包只由服务器发送，客户端不提交额外开奖或领奖请求。记录真实物品数量和共享 NBT，批量合并相同物品；通知外的命令奖励引用已选中的定义。结果展示上限为 128 种，超过部分提示已发放，发奖本身不受此显示上限影响。库存满时仍按原有发放/掉落逻辑处理。

提前关闭、跳过、缩放与开关动画均不改变发奖。自动领取不弹出此界面；若结果到达时正在其他界面操作，暂存展示队列，最多 16 个界面，超过时退回奖励提示；断开服务器清理队列。配置在客户端独立保存，专服不加载动画类。

## 视频进度条（modern.7）

正文视频显示当前时间与总时长，点击进度条或拖动后松开可跳转。原生播放器的播放 / 暂停状态保持，拖动过程只预览目标，不重复提交定位。拖出控件后松开会钳制首尾；关闭界面取消拖动。

进度条支持本地导入、可定位的 HTTP(S) 和 B 站游客流。未知时长显示 `--:--`，源未就绪或不支持定位时禁用进度操作，不会误触播放、重试或打开网页。播放 / 暂停、重播、B 站重试 / 网页使用矢量图标，保持字体与资源包独立。32 像素控制栏上方进度条，下方左侧播放、中间时间、右侧辅助操作。悬停显示本地化说明，按下和悬停有状态反馈；鼠标移出后松开取消按钮操作。窄宽度下优先保留图标，时间缩为当前位置或通过悬停查看。

Media API 1.0.2 提供 `positionMillis()`、`durationMillis()`、`isSeekable()`，时间均以毫秒表示。共用每 100 ms 一次的轻量原生状态查询；不触发下载、解析或纹理上传。任务数据、媒体路径和自由画布尺寸保持原语义。

## 正文媒体自动尺寸（modern.6）

图片、Markdown 图片与视频省略宽高时自动铺满正文可用宽度，按原始比例计算高度；仅指定宽度时同样等比计算。图片异步解码、视频开始解码取得尺寸后，原控件更新高度并重排下方正文和滚动范围。宽窄编辑器预览共用此行为，已明确填写的尺寸保留，计算结果不写入任务 JSON。

视频元数据由 Media API 1.0.1 的 `width()` / `height()` 提供。尺寸未知时使用封面比例或 16:9 占位；不会为布局扫描所有屏幕外视频或同步下载媒体。较长的自动图片高度可超过旧 512 像素占位框。

## 独立媒体 API（modern.5）

视频后端由独立 `MediaAPI-1.0.0.jar` 提供，任务系统为可选接入。官方 WATERMeDIA 1.3.43 JAR 原样内置，首次使用后台释放并校验，无需下载 Java 运行库；原生 VLC/libVLC 的平台要求仍适用。

公共 API 包为 `dev.yudream.media.api.client`。提供本地 / HTTP / B 站来源、后台自定义解析、播放器生命周期、纹理、播放/暂停/重播/跳转、错误枚举与中文诊断。没有 FTB Library 或任务系统依赖；专服不加载客户端或原生后端。接口说明见相邻 Media API 工程的 `README.md`。

任务定义、媒体 `media:` / `local:` / 资源包路径、任务 ID、团队 UID、进度与领奖格式未变。

## 编辑响应

modern.2 对单对象编辑采用局部缓存失效，保留无关任务的图标和文本缓存；JEI / HEI 只重建受影响任务的配方索引，并合并同 tick 的重复更新。索引更新在客户端主线程进行，每 tick 最多 8 个任务、约 2 ms 预算；单个外部物品过滤器调用可能超过预算。全量任务书加载及全局配置变更仍需完整索引更新。

任务移动先更新本地画布，确认回包带本次客户端会话及请求序号。较旧的确认不会覆盖后续修改；最新确认与本地内容一致时不重建界面。权限拒绝会返回服务端原数据供校准。序号只用于网络同步，不写入任务书、团队进度或领奖记录。

## 游戏内正文编辑器（modern.3）

“编辑文本”使用游戏内界面，支持标题、副标题、多行源码、选择、换行、滚动、粘贴、正文撤销/重做和实时预览。组件表单也在游戏内。宽屏并排预览，窄屏切换标签；预览点击不执行任何链接动作。正文预览在停止输入约 3 tick 后更新，输入本身立即显示，不为每个字符刷新整本任务书。

旧正文默认使用原版模式；新空正文默认使用 Markdown。原样保存保留完整原列表；编辑旧文本时保留尾部空行。Markdown 用原 `text` 列表中的独立 JSON 组件承载；本轮没有增加任务文件顶层字段、改变 ID 或进度结构。该组件可保存任意正文，源码仍允许混排既有 JSON 行。未知组件/扩展字段不主动转换或删除。

支持的 Markdown 子集及示例见 [README](../README.md#markdown-模式)。不支持 HTML、完整 CommonMark、复杂嵌套列表与表格内点击动作。Markdown 的 ZS 链接和既有 ZS 组件均由服务端核对原始任务中的动作声明；代码块和行内代码中的链接不作为可执行声明。

## 媒体与选择器（modern.4）

- 正文及画布媒体资源支持游戏内文件选择框。读取目录、复制、哈希与传输在后台完成；原文件不修改，服务端确认后填入资源路径。图片、视频及视频封面均有入口。
- 新导入的视频仅复制到客户端 `config/ftbquests/media/`，使用原 `media:` 路径；图片继续保存在服务器并按需获取到客户端缓存。图片上限 8 MiB，视频 256 MiB；图片分片、哈希校验、权限、取消、超时和暂存配额内置。媒体不参与 `normal/` 的每次保存事务，搬服和备份需要单独保留 `media/`。
- 正文任务链接及任务右键的添加 / 移除前置，复用任务选择器；可搜索名称、章节名及 8 位 ID。添加依赖继续检查循环，不改变实际 ID 或依赖格式。
- 正文物品模型提供物品选择器，按本地化名称搜索。保留注册名、Damage、tag NBT；`size` 控制模型大小，省略此字段的旧物品组件保持原样。
- B 站普通视频链接、BV / av 号、短链、分 P 和起播时间可以进入在线解析；仅保存原链接，临时地址留在内存，VLC 使用流播放。modern.5 使用可选 Media API Mod 中内置的 WATERMeDIA，仍需可加载的原生 VLC。失败可重试或转网页；不提供登录、付费、直播和番剧解析。

B 站的普通公开视频已在无代理进程中实际解码，描述控件的暂停、重试及不写媒体文件检查通过；原先继承代理环境时的 TLS EOF 不再作为功能阻断。此结果只代表测试视频与网络组合，游客限制、其他地区、视频编码和接口变更仍可能影响播放。受控 HTTP 流与 B 站实站验证分开记录。此段为之前版本的实站验收历史；modern.12 的初始连接实现遇到 TLS EOF，改用独立 TLS / DIRECT 的视频专用 HTTP 客户端后，已在环境与 JVM 代理均开启的场景通过 B 站实播、暂停、进度跳转及重试。抖音新增实验解析，其他网站仅支持视频直链。完整入口与边界见 [README](../README.md#图片和视频)。

| --- | --- |
| `progression_mode` | 任务从章节继承，章节从任务书继承；DEFAULT 保持原行为 |
| `require_sequential_tasks` | 子任务按列表顺序开启；可选任务不阻止后续必做任务 |
| `optional_task` | 子任务不参与必做完成条件 |
| `min_required_tasks` | 至少完成指定数量的必做子任务；0 沿用默认全部/或条件 |
| `chapter_prerequisites` | int 数组，引用其他章的任务 ID；必须全部完成 |
| `hidden_dependency_lines` / `hover_dependency_lines` | int 数组，分别为隐藏与悬停揭示的前置连线；不修改实际前置关系 |
| `excluded_quests` | 与其他任务的完成互斥关系，仍使用旧 int ID |
| `reach_day` | `worldTime / 24000`，从第 0 天计数 |
| `timer` | 按游戏秒或真实时间累计；持久化计时状态；同团队同 tick 去重 |
| `structure` | 原点和维度按团队任务状态持久化；服务端重新匹配 |
| 复制粘贴 | 新任务和子对象重新分配 ID，并重映射内部引用；不复制团队进度 |
| 未知字段/未知类型 | 保留原 NBT 及引用，未知类型不视为自动完成 |
