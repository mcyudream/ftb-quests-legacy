# 中文输入与拼音搜索（modern.16 / Library modern.4）

## 输入中文

输入框右侧点击 **中**，或聚焦后按 **F4**，打开内置系统输入法编辑窗口。切换平时使用的系统输入法即可使用组合输入和候选词：

1. 在窗口中输入／修改文字，单行适用于标题、搜索、配置等，多行适用于正文源码。
2. 点击“接受”或按 Ctrl+Enter 回填游戏。Enter 在输入法里照常选择候选词，多行框内可换行。
3. 点击“取消”或关闭窗口，原文字不变。离开原游戏界面时该窗口自动取消，延迟返回不会写进另一处任务。

正文回填保持换行和 Unicode，作为一次编辑操作，可使用 Ctrl+Z／Y 撤销／重做；只有点击任务编辑器保存后才发往服务端。单行框沿用原有允许字符、字数与有效性检查；未修改的旧长文本不会因打开后确认被截短。

游戏内原有 Unicode 字符输入仍可用，输入法提交的无物理键码字符不会被当作编辑快捷键。扩展汉字的原生窗口回填和删除不拆开 UTF-16 代理对。

系统输入法窗口使用 JDK 自带的 AWT 原生文字控件，没有另打包输入法、词库或额外 Mod。它需要桌面会话及已安装／配置好的系统输入法；这也给 GLFW 直接输入不可用的环境提供编辑入口。**没有修改 Cleanroom／GLFW 的底层输入法实现，也不宣称所有平台均能在游戏内直接显示候选窗。** 无桌面或被禁用 AWT 时会提示不可用，原有直接输入和粘贴入口保留。

## 物品选择

| 输入 | 示例目标 |
| --- | --- |
| `铁锭` | 铁锭 |
| `tieding` / `tie ding` | 铁锭 |
| `td` | 含对应连续拼音首字母的物品，如铁锭 |
| `iron_ingot` / `minecraft:iron_ingot` | 注册名匹配 |
| `@minecraft` | 模组命名空间过滤 |
| `lvbaoshi` / `lübǎoshí` / `lubaoshi` | 绿宝石 |

继续匹配玩家当前语言的显示名称、英文／注册名。名称含中文时增加无声调全拼、紧连全拼和连续首字母；支持空格分词、拼音撇号、大小写、全角拉丁字母及 ü／v／u: 写法。搜索只选择原物品栈，不重建／改写注册名、meta 或 NBT。

## 思索选择

同样匹配入口物品名、教程／场景标题和精确教程 ID。例如“能源核心结构搭建”可用 `nengyuanhexinjiegoudajian` 或 `nyhxjgdj` 查找。选中后仍返回 `mod:item#pack:scene` 原始 ID，不将中文或拼音写成链接目标。

Ponder 继续是可选独立前置；未安装时使用原有缺失提示。本轮没有改动 Ponder 运行库。

## 性能与边界

使用正式 Cleanroom 0.4.0 自带的 ICU Han-Latin 转写，未添加下载、联网查询或新的运行库。物品名称及变体仍在客户端线程按批读取；拼音转换在后台生成和预热，缓存最多 32768 个名称。搜索查询只规范化一次，游戏主线程不为每个物品重新转拼音；思索也从元数据在后台建索引。

中文多音字采用 ICU 的转写结果，不能保证每个人名、方言读法和自定义词都拥有全部读音别名。拼音依据当前显示名称；英语界面中的纯英文物品名不凭空补充另一套中文语言包名称。

## 安装与验证

客户端和服务端同时替换：

- `FTBQuests-1202.10.0-modern.16.jar`
- `FTB-Library-NovaEng-5.5.4-modern.4.jar`

其他依赖沿用上一包。任务 ID、团队整数 UID、进度、领奖及存储格式不变。

正式 CR 0.4.0 的客户端已验证中文字符事件、真实 AWT 单／多行控件、确认／取消／关闭生命周期、正文撤销及中文数据服务端保存重读；物品和思索测试走实际筛选界面并校验选择结果。**系统输入法引擎的真实候选词按键流程没有自动化实测**，原生窗口验收通过 AWT 控件／事件和回填检查，不把程序设入文字称为实际输入法组合验证。Windows/macOS 未实测。最终场景、单元测试和产物哈希见 [验收报告](../verification/REPORT.md)。

实现参考：[GLFW 文本字符输入](https://www.glfw.org/docs/3.4/input_guide.html#input_char)、[ICU 转写](https://unicode-org.github.io/icu/userguide/transforms/general/)。
