# modern.16 / Library modern.4：中文输入与拼音搜索验收

生成时间（UTC）：2026-11-07T07:11:46.937792+00:00。Minecraft 1.12.2，正式 **Cleanroom 0.4.0（不带 alpha）**，Java 25，Linux x86_64。3 个最终场景使用交付 JAR，非 userdev，全部退出码 0，无超时。

## 完成内容

- 单行输入与正文源码提供“中”按钮和 F4 系统输入法编辑入口。窗口采用 JDK 原生 AWT 文本控件及输入法上下文；确认在 Minecraft 客户端线程回填，取消保持原文，离开原屏幕自动取消。游戏原有 Unicode 直接输入路径保留。
- 原生多行回填保留 Unicode、中文标点及换行，规范化平台换行，为一次可撤销操作。单行沿用字数／允许字符验证；修复回删时的光标位置及扩展汉字代理对拆分。
- 物品支持中文、英文、注册名、全拼、连续首字母及 @模组过滤。思索选择器匹配入口物品、教程标题和 ID，全拼／首字母选择仍返回准确原 ID。
- 使用 Cleanroom 自带 ICU Han-Latin，不增加额外运行库／输入法 Mod，不访问在线服务。名称读取继续按批在客户端线程完成；转写在后台生成、预热，缓存最多 32768 项，查询只规范化一次。
